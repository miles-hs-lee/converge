# Converge Logo Concepts

- `converge-orbit.svg`: Multi-tenant streams converging to a single center. Best for product identity.
- `converge-link.svg`: Linked paths that emphasize account connection and sync.
- `converge-nodes.svg`: Hub-and-spoke network for people search and org graph.
- `converge-fold.svg`: Bold geometric mark for high contrast app icon use.

## Recommended Pick

- Primary recommendation: `converge-orbit.svg`
- Reason: Most clearly communicates "many sources -> one workspace" while staying simple at small icon sizes.
